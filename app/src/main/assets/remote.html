Full Control

✓ Set up. The TV turns its Accessibility Service on by itself.
One-time setup so the TV switches Minimal Launcher’s Accessibility Service on by itself (needed for the remote to control other apps and to pick TiviMate channels).
1. On the TV: Settings › System › About › select “Android TV OS build” 7 times. Then Settings › System › Developer options › turn on USB debugging.
2. Install iSH Shell (free) from the App Store, open it and run these one at a time (tap to copy). Choose Allow on the TV when it asks.
If “adb connect” is refused: in Developer options turn on Wireless debugging › Pair device with pairing code, run adb pair IP:PORT CODE, then connect to the IP:port it shows.

Tip

Tap Share › Add to Home Screen in Safari to keep this remote one tap away.
